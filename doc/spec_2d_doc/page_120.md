# Documents 27 et 28

O<sup>(1)</sup> : Obligatoire s'il n'est pas possible de suivre la structure de la norme postale. Si ce champ est fourni, les champs 6U, 6W, 6X et 6Y sont facultatifs.
O<sup>(2)</sup> : Obligatoire si la structure de la norme postale peut être suivie. Si l'ensemble de ces champs sont fournis, le champ 4Y devient facultatif.

De plus, l'ensemble des champs non mentionnés dans le tableau des catégories suivantes peuvent être utilisés en tant que champ facultatif :
- Identifiants de données complémentaires du code 2D-DOC (cf. section 7.0)
- Identifiants de données fiscales (cf. section 7.3)
